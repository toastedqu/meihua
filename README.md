# 梅花易数排盘

参照 `../liuyao` 的简洁表单和分层设计：Python 确定性引擎、FastAPI、本地网页，以及同一引擎在 Pyodide 中运行的静态站点。无 LLM、数据库、API 密钥或访问追踪，不保存所占之事。

站点：<https://toastedqu.github.io/meihua/>。源码仓库：<https://github.com/toastedqu/meihua>。

## 运行

Python 3.12 或更新版本：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

打开 <http://127.0.0.1:8001/>；`GET /healthz` 为健康检查。端口8001避开隔壁六爻默认的8000。

纯静态构建与预览无需安装 Python 包：

```bash
python3 scripts/build_static_site.py
python3 -m http.server 8124 --directory site --bind 127.0.0.1
```

打开 <http://127.0.0.1:8124/>。首次需从 jsDelivr 下载固定版本的 Pyodide，之后由浏览器缓存；引擎、64卦卦辞与彖象辞、384条爻辞与小象辞、八卦类象随站点分发，运行时不联网取文。没有把几行算术重写成第二个 JavaScript 引擎；服务器与浏览器共用 `app/engine.py`。

`.github/workflows/pages.yml` 在推送 `main` 后检查并发布 `site/`，也支持手动触发。仓库 Settings → Pages 的 Source 使用 GitHub Actions；`github-pages` 环境部署成功后更新上述站点。

## 算法与约定

- 双数：`上 = 第一数 % 8 or 8`，`下 = 第二数 % 8 or 8`，`动 = (上 + 下 + 时辰数) % 6 or 6`。加的是**余0已折算为8的两个卦数**，不是原始两数，也不是未折算的0。
- 三数：前两数照常定卦，`动 = 第三数 % 6 or 6`。不加前两数，不加时辰。
- 输入接受0及非负整数。浏览器全程按字符串传数，最多100位，避免超过 JavaScript 安全整数后失真；API 的大整数也必须用字符串。
- 子到亥依次为1至12，子时23:00至次日01:00，各时段含起点不含终点。由用户明确选择，不隐式推断时区或时辰。
- 爻序自下而上。初至三爻动，下卦为用、上卦为体；四至上爻动，上卦为用、下卦为体。
- 互卦取二三四爻为下互、三四五爻为上互；变卦只翻转动爻。本卦为当下、互卦为过程、变卦为结果。
- **乾坤无互，互其变卦**：本卦为纯乾或纯坤时，互卦改从变卦的爻取；边爻动时所取互卦仍可能是纯卦。其余62卦仍从本卦取互。体用仍按本卦判定。
- 旺衰由用户选月令，不用公历月份、设备日期或未经交节计算的日期代替。四季为辰戌丑未月末各十八天，不是四个整月；这个期间选“四季”，其余选所属春夏秋冬。本版不自动计算交节。
- 所占之事仅为记录和显示，不参与确定性算法，不据文字猜测分占类型或外应。

| 月令 | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春（寅卯辰） | 木 | 火 | 水 | 金 | 土 |
| 夏（巳午未） | 火 | 土 | 木 | 水 | 金 |
| 秋（申酉戌） | 金 | 水 | 土 | 火 | 木 |
| 冬（亥子丑） | 水 | 木 | 金 | 土 | 火 |
| 四季末十八天 | 土 | 金 | 火 | 木 | 水 |

例：双数 `8、8`，子时：上下均坤，`(8+8+1)%6=5`，五爻动；绝不能按`(0+0+1)%6`排初爻。

## 展示顺序与断法

1. **盘**：本卦、互卦、变卦六爻图与卦名，以及所占之事、起卦数字、时辰、月令、动爻及体用。
2. **吉凶判定**：四行影响表（阶段、体、用、体用生克、通则倾向、旺衰修正）。体互、用互、变卦用卦一律与**本卦之体**比较。
3. **卦象**：体、用两卦的完整类象对照表（可收起）。
4. **卦爻辞**：本卦与变卦各列卦辞、彖辞、象辞；动爻列爻辞及其小象辞。乾坤单爻动不取用九、用六。

五种关系：用生体与比和偏吉；体克用按一般人事通则偏吉但须体有力；体生用为耗泄；用克体为受制。每一阶段均列旺衰修正。旺相与休囚死的强弱文字是本项目的定性转述，不是量化权重。互变不重新定体，变卦中未改变的静体不重复计一次助力。

无吉凶百分比，无简单多数投票，无自动的具体事件、应期、医学或产育结论。

## API

```http
POST /api/v1/chart
Content-Type: application/json

{"method":"two","numbers":["12","23"],"hour":1,"season":"autumn","question":"所占之事"}
```

三数示例：

```json
{"method":"three","numbers":["12","23","6"],"season":"autumn"}
```

`method` 为 `two` 或 `three`；`season` 为 `spring`、`summer`、`autumn`、`winter` 或 `earth`。三数法不得提交非空 `hour`。未知字段、非法输入均返回明确的 `422 {"detail":"…"}`。

响应含 `original`、`mutual`、`transformed`、`moving_line`、`body`、`use`、`influences`、`imagery`、`texts`。卦象记录含 `judgment`、`tuan`、`xiang`、`line_texts`、`line_xiang`；`texts` 为三段文章，每段含 `title`、`passages`（`label` 与 `text`）及 `source`。`lines` 自下而上，以1为阳、0为阴。数字在响应中仍为字符串。静态桥接 `app.engine.handle()` 返回 `{status, ok, payload}` 封装，HTTP 返回其中的 `payload` 与相同状态码。

## 数据出处与更新

`app/data/classics.json` 是随应用发布的资料，不依赖在线抓取：

- 卦爻辞与彖象辞：[维基文库《周易》](https://zh.wikisource.org/wiki/周易)六十四卦页的公版古经与十翼段落，取简体显示，每卦保存来源与修订号。每卦含卦辞、彖辞、大象辞、六条爻辞及六条小象辞；乾坤的用九、用六及其小象、文言不收。
- 八卦类象：按类别人工整理的物象条目（天时、地理、人物、身体、动物、静物、屋舍、饮食、疾病、方道、五色、数目、五味等），只保留实体与性情条目，不含分占断语、行动建议或结果预测。
- 类象为已整理条目，不声称穷尽所有类象或版本。原文的时代观念不代表本项目认同。

显式刷新卦爻辞（缓存置于工作目录外，不随发布）：

```bash
python3 scripts/import_classics.py --cache /tmp/meihua-classical-sources
```

导入器逐页校验六条爻辞、六条小象、彖辞与大象辞及六十四卦序，来源不完整即报错，绝不静默跳过；已整理的类象原样保留。源站请求有限速及有限重试，不应高频运行。更新后须检查文本差异。
