# 梅花易数排盘

参照 `../liuyao` 的简洁表单和分层设计：Python 确定性引擎、FastAPI、本地网页，以及同一引擎在 Pyodide 中运行的静态站点。无 LLM、数据库、API 密钥或访问追踪，不保存所占之事。

站点：<https://toastedqu.github.io/meihua/>。源码仓库：<https://github.com/toastedqu/meihua>。

## 运行

Python 3.12 或更新版本：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
```

打开 <http://127.0.0.1:8001/>；`GET /healthz` 为健康检查。端口8001避开隔壁六爻默认的8000。

纯静态构建与预览无需安装 Python 包：

```bash
python3 scripts/build_static_site.py
python3 -m http.server 8124 --directory site --bind 127.0.0.1
```

打开 <http://127.0.0.1:8124/>。首次需从 jsDelivr 下载固定版本的 Pyodide，之后由浏览器缓存；引擎、64卦卦辞、384条爻辞与类象随站点分发，不运行时爬取原书。没有把几行算术重写成第二个 JavaScript 引擎；服务器与浏览器共用 `app/engine.py`。

`.github/workflows/pages.yml` 在推送 `main` 后检查并发布 `site/`，也支持手动触发。仓库 Settings → Pages 的 Source 使用 GitHub Actions；`github-pages` 环境部署成功后更新上述站点。

## 算法与约定

- 双数：`上 = 第一数 % 8 or 8`，`下 = 第二数 % 8 or 8`，`动 = (上 + 下 + 时辰数) % 6 or 6`。加的是**余0已折算为8的两个卦数**，不是原始两数，也不是未折算的0。
- 三数：前两数照常定卦，`动 = 第三数 % 6 or 6`。不加前两数，不加时辰。
- 输入接受0及非负整数。浏览器全程按字符串传数，最多100位，避免超过 JavaScript 安全整数后失真；API 的大整数也必须用字符串。
- 子到亥依次为1至12，子时23:00至次日01:00，各时段含起点不含终点。由用户明确选择，不隐式推断时区或时辰。
- 爻序自下而上。初至三爻动，下卦为用、上卦为体；四至上爻动，上卦为用、下卦为体。
- 互卦统一取本卦二三四爻为下互、三四五爻为上互；变卦只翻转动爻。本卦为当下、互卦为过程、变卦为结果。
- **纯乾坤的异例**：原书另载“乾坤无互，互其变卦”。本系统不暗中切换，在纯乾坤结果上明确提示；仍显示统一取法的互卦。
- 旺衰由用户选月令，不用公历月份、设备日期或未经交节计算的日期代替。四季为辰戌丑未月末各十八天，不是四个整月；这个期间选“四季”，其余选所属春夏秋冬。本版不自动计算交节。
- 所占之事仅为记录和显示，不参与确定性算法，不据文字猜测分占类型或外应。

| 月令 | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春（寅卯辰） | 木 | 火 | 水 | 金 | 土 |
| 夏（巳午未） | 火 | 土 | 木 | 水 | 金 |
| 秋（申酉戌） | 金 | 水 | 土 | 火 | 木 |
| 冬（亥子丑） | 水 | 木 | 金 | 土 | 火 |
| 四季末十八天 | 土 | 金 | 火 | 木 | 水 |

此表及两种起卦法以需求定义为准。原书概述也有以“辰戌丑未月”论土旺的写法，不用它覆盖这里的十八天定义。

例：双数 `8、8`，子时：上下均坤，`(8+8+1)%6=5`，五爻动；绝不能按`(0+0+1)%6`排初爻。

## 展示顺序与断法

1. 本卦、互卦、变卦六爻图及名称，标明动爻、体用、体互／用互。
2. 先按本卦体用给一般人事倾向，再列体互、用互及变用相对**原体**的生克与旺衰，说明过程和结果。
3. 体、用所属八卦的完整类象对照，含第二章属类、第三章分项及第十二章卦应。保留全部已列条目，不截断；可收起整张表。
4. 本卦卦辞、对应动爻爻辞、变卦卦辞。乾坤单爻动也不以用九、用六替代。
5. 其他原书规则、章节出处，以及已实现／未实现的边界。

五种关系依据[第四章《体用总诀》](https://www.quanxue.cn/qt_mingxiang/meihua/meihua05.html)：用生体与比和偏吉；体克用按一般人事通则偏吉但须体有力；体生用为耗泄；用克体为受制。每一阶段均列出旺衰修正。旺相和休囚死的强弱文字是本项目依据原书的**定性转述**，不是原书给出的量化权重。互变不重新定体，变卦中未改变的静体不重复计一次助力。

无吉凶百分比，无简单多数投票，无自动的具体事件、应期、医学或产育结论。体互比用互较切，通过角色及说明呈现，不编造权重。体党用党、相互制化只说明适用规则，不伪装已完成全局裁决。

## 原书另有的规则

| 规则 | 原书位置 | 本页处理 |
|---|---|---|
| 乾坤无互、互其变卦；其他起卦方式 | 第一章《象数易理篇之一》 | 异例提示；只实现指定双数、三数 |
| 人事情理可优先于机械体用，同卦不能套同一故事；先天、后天看辞侧重不同 | 第四章《体用生克篇之一》 | 提供辞象，不生成具体故事 |
| 天时、人事、家宅、屋舍、婚姻、生产、饮食、求谋、求名、求财、交易、出行、行人、谒见、失物、疾病、官讼、坟墓十八分占 | 第五章《体用生克篇之二》 | 自动判读仅限一般人事通则；天时不分体用，生产及饮食等另有例外 |
| 三要（耳目心）与十应、内外合参 | 第六、七、十二章 | 未输入外应，不虚构外应；十应含正、互、变、方、日、刻、外、天时、地理、人事 |
| 生体之卦被克则减助，克体之卦受制可缓；党众、旺衰、向背、静占 | 第四、七章 | 显示旺衰与各作用卦，不以简单计分代替全盘制化 |
| 观宅气、起卦加姓数、器物成毁、种植畜养 | 第八章《体用生克篇之五》 | 不额外加姓数，不自动套用器物专断 |
| 体互与用互、真生真克的轻重、动静迟速、坐端八方与应期 | 第九章《断占总诀篇之一》 | 已标体互用互；其余需额外情境，未自动化 |
| 饮食细则、观物类例、射覆、卦的反对性情、变爻位置与物数 | 第十、十一章 | 仅作为另外的原书规则说明，不混入一般人事结论 |

原书不是单一无例外的公式。正文中也有疑似讹字、矛盾例句；程序以明确的五行表、体用规则及需求算法为准，不将每段古文直接当作可执行规则。古代疾病、医药、产育、官讼等内容仅供文献研究，不提供诊疗、用药、法律或投资建议。

## API

```http
POST /api/v1/chart
Content-Type: application/json

{"method":"two","numbers":["12","23"],"hour":1,"season":"autumn","question":"所占之事"}
```

三数示例：

```json
{"method":"three","numbers":["12","23","6"],"season":"autumn"}
```

`method` 为 `two` 或 `three`；`season` 为 `spring`、`summer`、`autumn`、`winter` 或 `earth`。三数法不得提交非空 `hour`。未知字段、非法输入均返回明确的 `422 {"detail":"…"}`。

响应含 `original`、`mutual`、`transformed`、`moving_line`、`body`、`use`、`influences`、`imagery`、`texts`、`additional_rules`。卦象的 `lines` 自下而上，以1为阳、0为阴；`line_texts` 同序。数字在响应中仍为字符串。静态桥接 `app.engine.handle()` 返回 `{status, ok, payload}` 封装，HTTP 返回其中的 `payload` 与相同状态码。

## 数据出处与更新

`app/data/classics.json` 是随应用发布的资料，不依赖在线抓取：

- 类象：[劝学网《梅花易数》](https://www.quanxue.cn/qt_mingxiang/meihuaindex.html)第二、三、十二章的公版古文，完整保留类别和古称；卦宫八卦原文中的“兑为金”“泽天决”等疑似讹字也保留，排盘卦名则用规范名。
- 卦爻辞：[维基文库《周易》](https://zh.wikisource.org/wiki/周易)六十四卦页的公版古经段落，取简体显示，每卦保存来源及修订号。只提取古经，不收现代译注、网页模板或《彖》《象》等未要求的附文。
- “全部类象”是所引篇章的完整条目，不声称穷尽无穷类象或所有版本。原文的时代观念不代表本项目认同。

显式刷新数据（缓存置于工作目录外，不随发布）：

```bash
python3 scripts/import_classics.py --cache /tmp/meihua-classical-sources
```

导入器逐页校验六条爻辞、六十四卦序与八种类象类别，来源不完整即报错。源站请求有限速及有限重试，不应高频运行。更新后须检查文本差异。
